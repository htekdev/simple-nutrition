# Simple Nutrition

**Know your number. Protein first. Portion moves.**

A nutrition website that makes calorie-controlled, high-protein eating understandable to anyone — no nutrition degree required.

## What is this?

Simple Nutrition is a food-budget system. You get a daily calorie and protein budget, split into "boxes" (eating occasions). Each box is built using four steps:

1. **Anchor** — Start with protein
2. **Fill** — Add volume (veggies, fruit)
3. **Dial** — Adjust portions of carbs/fats
4. **Flavor** — Season generously

## Tech Stack

- Pure HTML / CSS / JavaScript
- No frameworks, no build tools
- GitHub Pages deployment
